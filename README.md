# Portfólio · Julio Mendes

Site em React + Vite. Mensageria, automação e IA.

## Rodar localmente
```bash
npm install
npm run dev
```

## Editar conteúdo
Todos os textos, projetos e links ficam em `src/data/content.js`.
Preencha `linkedin`, `email` e `whatsapp` em `profile` para os botões de contato aparecerem.

## Publicar na Vercel
Importe este repositório na Vercel. Ela detecta o Vite sozinha (build `npm run build`, saída `dist`).
